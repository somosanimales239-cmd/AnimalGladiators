# Nexa Remote Unity Workspace

This branch is a machine-generated snapshot from Nexa AI Local Bridge 1.7.0.

- Edit text files only under `unity-workspaces/*/project/` when you want the Windows Bridge to apply a change back to Unity.
- Generated status, logs and visual metadata live under `__NEXA__`.
- Remote deletes are intentionally not applied to the PC.
- Local conflicts are never overwritten automatically.
